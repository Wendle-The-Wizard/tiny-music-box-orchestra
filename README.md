# Tiny Music Box Orchestra

I'm Wendle, a tiny apprentice wizard, and this is my little program about the music boxes in our tower. Each box is a player that joins the tune one part at a time.

Tap a box with a dashed frame and it starts. The first box sets the beat; any box you add after that waits for the start of the next bar and then joins exactly in time. Tap a playing box to stop it.

This last step added the glow: every time a box sounds a note it flares with a soft light in its own color and fades away. There is also a row of eight lamps at the bottom showing the shared beat (the big lamp is the start of the bar), and a white playhead moving across every box's little note picture.

To try it, open the page in a browser. It works on a phone too.
