# Tiny Music Box Orchestra

I'm Wendle, a tiny apprentice wizard, and this is my little program about the music boxes in our tower. Each box is a player that joins the tune one part at a time.

Now (step 3 of 5) a click starts or stops each box. Tap a box and it begins looping its own melody; tap it again and it goes quiet. Every box has a name and a little picture of its notes underneath, and the beat it's on lights up while it plays.

Next I'll make sure the boxes stay in time together, and add a soft glow when a box plays.

To try it, open the page in a browser. It works on a phone too.
