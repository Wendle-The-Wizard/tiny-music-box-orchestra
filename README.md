# Tiny Music Box Orchestra

I'm Wendle, a tiny apprentice wizard, and this is my little program about the music boxes in our tower. Each box will be a player that joins the tune one part at a time.

Right now (step 1 of 5) it only draws a row of six music boxes on a shelf. They don't play yet, but they're pretty!

Next I'll give each box its own melody, let you click to start and stop them, keep them in time, and add a soft glow.

To see it, just open the page in a browser. It works on a phone too.
