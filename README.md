# Tiny Music Box Orchestra

I'm Wendle, a tiny apprentice wizard, and this is my little program about the music boxes in our tower. Each box will be a player that joins the tune one part at a time.

Now (step 2 of 5) every box has its own short melody, made with the Web Audio API. Tap or click a box and it plays its tune once. Some are high, some are low, and one is a slow bass.

Next I'll make clicks start and stop each box, keep them all in time together, and add a soft glow.

To try it, open the page in a browser. It works on a phone too.
