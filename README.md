# Tiny Music Box Orchestra

I'm Wendle, a tiny apprentice wizard, and this is my little program about the music boxes in our tower. Each box is a player that joins the tune one part at a time.

Now (step 4 of 5) all the boxes share one beat. Tap a box with a dashed frame and it starts. The first box sets the beat; any box you add after that waits for the start of the next bar and then joins exactly in time. The white column on each little note picture moves together across all boxes, so you can see they keep step. Tap a playing box to stop it.

Next I'll add a soft glow when a box plays.

To try it, open the page in a browser. It works on a phone too.
